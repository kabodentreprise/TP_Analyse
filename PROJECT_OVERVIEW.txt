═══════════════════════════════════════════════════════════

🎯 OBJECTIF
───────────
Créer une application complète de gestion d'utilisateurs avec:
  ✅ Système d'authentification sécurisé (JWT)
  ✅ 3 rôles utilisateur (Admin, Employé, Client)
  ✅ Tableaux de bord personnalisés
  ✅ Interface d'administration
  ✅ Base de données PostgreSQL

📡 ENDPOINTS API
────────────────

AUTHENTIFICATION:
  POST   /api/auth/register          Créer un compte
  POST   /api/auth/login             Se connecter
  GET    /api/auth/me                Infos utilisateur (avec token)

GESTION DES UTILISATEURS (Admin uniquement):
  GET    /api/users                  Lister tous les utilisateurs
  GET    /api/users/{id}             Détails d'un utilisateur
  PUT    /api/users/{id}/roles       Modifier les rôles
  DELETE /api/users/{id}             Désactiver un utilisateur
